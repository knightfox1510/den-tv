How these are counted

  • Daily numbers come from a snapshot the den-tv stats workflow saves on the repo's stats branch every night (02:23 UTC); GitHub itself only keeps running totals. To save one now: GitHub › Actions › den-tv stats › Run workflow.
  • TVs active is an estimate: a TV that was off all day isn't counted, and one left on for days checks more often between restarts.
  • Downloads include anyone who downloads a file without installing it, and GitHub updates its counts with a delay of up to a few hours.
  • Website visitors are in Vercel Analytics: no cookies, and no personal data is kept.
